## 🛠️ Prerequisites & Setup

To run the programs in this repository locally, you need to set up your development environment:

1. **Install Java Development Kit (JDK):** Ensure you have JDK installed (refer to the guide in Lecture 02).
2. **Verify Installation:** Open your command prompt/terminal and run:
   ```bash
   java -version
   ```
3. **IDE (Optional):** You can use standard text editors like Notepad/VS Code or full IDEs like IntelliJ IDEA or Eclipse.
